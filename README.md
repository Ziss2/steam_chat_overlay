# Chat Overlay — Twitch + YouTube + Kick + TikTok

โอเวอร์เลย์แชทสำหรับสตรีม รวมแชท **Twitch**, **YouTube Live**, **Kick** และ **TikTok Live** มาไว้ในหน้าเดียว
รันเป็นเซิร์ฟเวอร์เล็ก ๆ บนเครื่องตัวเอง แล้วเอา URL ไปใส่ OBS เป็น **Browser Source**
ปรับธีมได้สด ๆ จากหน้า Config โดยไม่ต้องรีเฟรช OBS

```
Twitch IRC  ─┐
YouTube live ─┤
Kick WS     ─┼─► Node server (normalize) ─► WebSocket ─► /overlay  (Browser Source ใน OBS)
TikTok live ─┘                                         └─► /config   (หน้าตั้งค่า + พรีวิว)
```

## ฟีเจอร์

- **สี่แพลตฟอร์มพร้อมกัน** — Twitch, YouTube, Kick และ TikTok เปิด/ปิดแยกกันได้ในหน้า Config
- **Twitch** อ่านแชทแบบ anonymous IRC ไม่ต้องล็อกอิน
- **YouTube** ต่อได้ 2 วิธี — Data API v3 (ใส่ API key) หรือโหมดไม่ใช้ key (อ่านหน้า live chat โดยตรง)
  โหมด `auto` จะใช้ API ถ้ามี key และสลับไปโหมดไม่ใช้ key ให้เองเมื่อโควตาหมด
- **Kick** อ่านแชทสาธารณะผ่าน WebSocket ของ Kick (โปรโตคอลแบบ Pusher) โดยไม่ต้องล็อกอินหรือ API key
- **TikTok** อ่านแชทสดด้วยไลบรารี `tiktok-live-connector` แค่ใส่ชื่อผู้ใช้ (ไม่ต้อง token)
- **ไอคอนบอกแพลตฟอร์ม + สีชื่อ** แยกแต่ละแพลตฟอร์ม (หรือใช้สีที่ผู้ใช้ตั้งเองใน Twitch ก็ได้)
- **Badge** ซับ / มอด / VIP / Prime / เจ้าของช่อง / สมาชิก YouTube (โหลดรูปจริง มี fallback เป็นป้ายข้อความ)
- **อีโมท** Twitch native + BetterTTV + 7TV + FrankerFaceZ, ส่วน YouTube รองรับ emoji ของช่อง
- **Super Chat / Super Sticker / สมาชิกใหม่ / Bits (Cheer) / ซับ / Raid** แสดงเป็นการ์ดไฮไลต์พร้อมยอดเงิน
- **3 เลย์เอาต์** — การ์ด, กระชับ (ชื่อ: ข้อความ), และ **ฟองข้อความ + avatar**
- **avatar ผู้ชม** — Twitch ดึงจาก Twitch โดยตรง (สำรองด้วย decapi.me, แคชในเซิร์ฟเวอร์), YouTube ใช้รูปที่มาพร้อมข้อความ
- **หน้า Config ปรับสด** — ฟอนต์ ขนาด สี ความทึบ ตำแหน่ง อนิเมชัน จำนวนข้อความ เวลาซ่อนข้อความ ฯลฯ
  บันทึกทันทีและส่งไปอัปเดต overlay ที่เปิดอยู่ทุกตัว
- **ตัวกรอง** ซ่อนคำสั่งบอท บล็อกผู้ใช้ บล็อกคำ จำกัดความยาว
- ลบข้อความอัตโนมัติเมื่อมอดลบ/ไทม์เอาต์ (Twitch CLEARMSG/CLEARCHAT, YouTube deleted message)

## เริ่มใช้งาน

ต้องมี Node.js 20 ขึ้นไป (ทดสอบบน Node 22)

```powershell
npm install
npm start
```

จะได้:

- หน้าตั้งค่า → <http://127.0.0.1:4700/config>
- URL สำหรับ OBS → <http://127.0.0.1:4700/overlay>

ไฟล์ `config.json` จะถูกสร้างให้อัตโนมัติในครั้งแรก (แก้ผ่านหน้า Config ได้เลย ไม่ต้องแก้มือ)

> **เชื่อมต่อจากเครื่องอื่นผ่าน VPN/เครือข่าย**
> เซิร์ฟเวอร์รอรับที่ `0.0.0.0` (ทุกอินเทอร์เฟซ) แล้ว ให้เครื่องที่จะต่อใช้
> `http://<IP-ของเครื่องที่รันเซิร์ฟเวอร์>:4700/overlay` แทน `127.0.0.1`
> (IP จะแสดงใน log ตอน启动 เช่น `http://10.8.0.6:4700/overlay` สำหรับ IP ของ VPN)
> ถ้าอยากจำกัดเฉพาะในเครื่อง ตั้ง `HOST=127.0.0.1` ใน `.env` ได้
> ⚠️ ไม่มีระบบล็อกอิน — ใครต่อ IP นี้ได้ก็ดู/แก้ธีมได้ ให้ใช้ในเครือข่ายที่เชื่อถือได้เท่านั้น

### 1. ตั้งค่า Twitch

ใส่แค่ **ชื่อช่อง** (login เช่น `xqc`) ในหน้า Config แล้วเปิดสวิตช์ — ไม่ต้องใช้ token หรือ OAuth

### 2. ตั้งค่า YouTube

เลือกหนึ่งอย่าง:

| ช่อง | ใส่อะไร |
| --- | --- |
| ไลฟ์ที่กำลังสตรีมของตัวเอง | ใส่ **Channel ID / @handle / ลิงก์ช่อง** — ระบบจะหาไลฟ์ปัจจุบันให้เองทุก 30 วินาที |
| ไลฟ์เฉพาะรายการ | ใส่ **ลิงก์/ID วิดีโอ** (รับทั้ง `watch?v=`, `youtu.be/`, `/live/`) |

โหมดการเชื่อมต่อ:

- **ไม่ใช้ key (scrape)** — ใช้ได้เลย ไม่มีโควตา อ่านจากหน้า live chat ของ YouTube โดยตรง
  (ข้อควรรู้: ถ้า YouTube เปลี่ยนโครงสร้างหน้าเว็บ อาจต้องอัปเดตโค้ด)
- **API v3** — เสถียรตามสัญญา API แต่มีโควตา 10,000 หน่วย/วัน และ poll ครั้งละ ~5 หน่วย
  (ที่ 4 วินาที/ครั้ง ≈ 4,500 หน่วย/ชม. คือดูได้ราว 2 ชั่วโมงต่อวัน) เหมาะกับไลฟ์สั้น ๆ
- **อัตโนมัติ (แนะนำ)** — มี key ก็ใช้ API ก่อน พอโควตาหมดสลับไป scrape ให้เอง

ใส่ API key ได้ 2 ทาง: ช่องในหน้า Config หรือไฟล์ `.env` (ปลอดภัยกว่า เพราะไม่ถูกเขียนลง `config.json`)

```powershell
Copy-Item .env.example .env
# แก้ .env: YOUTUBE_API_KEY=AIza...
```

### 3. ตั้งค่า Kick

ใส่ **ชื่อช่อง** (slug บน kick.com เช่น `xqc`) แล้วเปิดสวิตช์ — ไม่ต้องล็อกอินหรือ API key
ระบบจะหา `chatroom id` จาก API สาธารณะ แล้ว subscribe แชทผ่าน WebSocket ของ Kick โดยอัตโนมัติ
รองรับข้อความ, อีโมทของ Kick, badge (มอด/ซับ/เจ้าของช่อง) และอีเวนต์ติดซับ

### 4. ตั้งค่า TikTok

ใส่ **ชื่อผู้ใช้ TikTok** (เช่น `nasher` หรือ `@nasher`) แล้วเปลิกสวิตช์ — ใช้ไลบรารี `tiktok-live-connector`
อ่านแชทสดได้ด้วยแค่ชื่อผู้ใช้ ไม่ต้อง token
รองรับข้อความแชท, อีเวนต์ของขวัญ (Gift) และสมาชิกเข้าร่วม (เปิด/ปิดได้ในหน้า Config)
ถ้าสตรีมยังไม่เริ่ม ระบบจะขึ้น "รอไลฟ์" และลองใหม่เองทุก 30 วินาที

> หมายเหตุ: TikTok ต้องการแพ็กเกจ `tiktok-live-connector` (เพิ่มใน `package.json` แล้ว)
> ถ้ายังไม่ได้ติดตั้งให้รัน `npm install` ก่อนรันเซิร์ฟเวอร์

### 5. ใส่ใน OBS

1. Sources → **+** → **Browser**
2. URL: `http://127.0.0.1:4700/overlay`
3. Width/Height: ให้กว้างกว่าค่า "ความกว้าง" ในธีมเล็กน้อย (เช่น ธีม 420 → Browser 440 × 900)
4. ติ๊ก **Shutdown source when not visible** ออก ถ้าไม่อยากให้แชทหายเวลาสลับซีน
5. ไม่ต้องใส่ Custom CSS — ปรับทุกอย่างจากหน้า Config ได้เลย

> พื้นหลังโปร่งใสอยู่แล้ว ถ้าอยากใช้ chroma key ให้ตั้งช่อง "พื้นหลังหน้า overlay" เป็น `#00ff00`

### เลย์เอาต์ฟองข้อความ

ในหน้า Config → "หน้าตา / ธีม" → **รูปแบบข้อความ** = `ฟองข้อความ + avatar` แล้วเปิด **รูปโปรไฟล์ผู้ชม (avatar)**
จะได้หน้าตาฟองสีครีม + ป้ายชื่อลอย + avatar กลม + ขยับเบา ๆ พร้อม:
- badge เป็นรูปจริง
- อีโมทตัดตำแหน่งถูกต้องแม้ข้อความมี emoji
- แชท YouTube + Super Chat ในฟองเดียวกัน, ลบข้อความตามที่มอดลบ, กรองบอท/คำ, ปรับสีฟอง-สีข้อความ-ขนาด avatar จากหน้า Config

ค่าธีมที่เกี่ยวข้อง: `layout`, `align` (avatar อยู่ฝั่งเดียวกับที่ชิด), `showAvatar`, `avatarSize`,
`bubbleColor`, `bubbleTextColor`, `liveMotion` (ป้ายชื่อขยับ + ฟองลอย)

### ทับค่าธีมเฉพาะบางซอร์ส (query string)

ใช้ทำหลาย ๆ ซอร์สที่หน้าตาไม่เหมือนกันจาก server ตัวเดียว:

| พารามิเตอร์ | ตัวอย่าง | ผล |
| --- | --- | --- |
| `platform` | `?platform=twitch` | แสดงเฉพาะแพลตฟอร์มนั้น (คั่นด้วย `,` ได้) |
| ชื่อค่าธีมใด ๆ | `?fontSize=26&width=360&showBadges=0` | ทับค่าธีมเฉพาะซอร์สนี้ |
| `debug` | `?debug=1` | โชว์สถานะเวลาต่อ WebSocket ไม่ติด |

ตัวอย่าง: แยกแชท Twitch ไว้ซ้าย, YouTube ไว้ขวา

```
http://127.0.0.1:4700/overlay?platform=twitch&width=380
http://127.0.0.1:4700/overlay?platform=youtube&width=380&align=right
```

## โครงสร้างโปรเจกต์

```
server/
  index.js            HTTP + WebSocket + REST API + ข้อความทดสอบ
  config.js           ค่าเริ่มต้น + config.json + .env (patch/บันทึก/แจ้งเตือน)
  hub.js              รวมข้อความ, ตัวกรอง, buffer สำหรับ overlay ที่เพิ่งเปิด
  message.js          รูปแบบข้อความกลาง (ทุกแพลตฟอร์มแปลงมาเป็นแบบนี้)
  util.js             logger, fetch, backoff, ตัวช่วยแปลง id/สี
  twitch/irc.js       IRC-over-WebSocket แบบ anonymous + parser IRCv3 tags
  twitch/assets.js    badge (Twitch GQL) + อีโมท BTTV/7TV/FFZ
  twitch/index.js     แปลง PRIVMSG/USERNOTICE เป็นข้อความกลาง
  avatars.js          หา avatar ของ Twitch (GQL + decapi.me) พร้อมแคช/รวมคำขอซ้ำ
  youtube/resolve.js  หา video id ของไลฟ์ปัจจุบันจากช่อง
  youtube/scrape.js   อ่านแชทผ่าน innertube (ไม่ใช้ key)
  youtube/api.js      อ่านแชทผ่าน Data API v3
  youtube/index.js    เลือกโหมด, retry, fallback เวลาโควตาหมด/ไลฟ์จบ
  kick/index.js        อ่านแชท Kick ผ่าน WebSocket (Pusher) + โปรไฟล์/อีโมท
  tiktok/index.js      อ่านแชท TikTok Live ผ่าน tiktok-live-connector
 public/
  overlay.html/js     ตัวโอเวอร์เลย์ (ใส่ใน OBS)
  config.html/js      หน้าตั้งค่า + พรีวิวสด
  css/                สไตล์ทั้งสองหน้า
```

## REST API (เผื่อทำปุ่ม/สคริปต์เพิ่ม)

| Method | Path | ใช้ทำอะไร |
| --- | --- | --- |
| GET | `/api/config` | อ่านค่าปัจจุบัน (API key ถูกปิดบัง) |
| PUT | `/api/config` | ส่ง patch บางส่วน เช่น `{"theme":{"fontSize":24}}` |
| GET | `/api/status` | สถานะการเชื่อมต่อของแต่ละแพลตฟอร์ม |
| GET | `/api/avatar?platform=twitch&login=xxx` | หา avatar (แคชในหน่วยความจำ ใช้ Twitch GQL + decapi.me สำรอง) |
| POST | `/api/reconnect` | `{"platform":"twitch"}` (ไม่ใส่ = ทุกแพลตฟอร์ม) |
| POST | `/api/test` | `{"platform":"tiktok","kind":"money"}` ส่งข้อความทดสอบ (`chat`/`money`/`sub`) |
| POST | `/api/clear` | ล้างข้อความบนจอ |

WebSocket อยู่ที่ `/ws` ส่ง event: `hello`, `chat`, `remove`, `clear`, `status`, `config`

## ปัญหาที่พบบ่อย

| อาการ | สาเหตุ/วิธีแก้ |
| --- | --- |
| แถบสถานะ YouTube ขึ้น "รอไลฟ์" | ยังไม่ได้เริ่มไลฟ์ หรือปิดแชท — ระบบจะลองใหม่เองทุก 30 วิ |
| YouTube ขึ้น "โควตาหมด" | โหมด `auto` จะสลับไป scrape ให้เอง ถ้าตั้ง `api` ไว้ให้เปลี่ยนโหมด |
| Twitch ไม่มีข้อความ | เช็กสะกดชื่อช่อง (ต้องเป็น login ไม่ใช่ชื่อโชว์) และช่องต้องมีคนคุยอยู่ |
| Kick ขึ้น "รอ/ต่อใหม่" ตลอด | เช็กสะกดชื่อช่อง (slug บน kick.com) ว่าเปิดช่องและมีแชทสดอยู่ |
| TikTok ขึ้น "รอไลฟ์" | ผู้ใช้ยังไม่ได้ไลฟ์ — ระบบลองใหม่เองทุก 30 วินาที (ลองเปิดไลฟ์หรือเช็กสะกดชื่อ) |
| Badge เป็นป้ายข้อความ ไม่ใช่รูป | โหลดรูป badge ไม่สำเร็จ (เน็ต/ปลายทางล่ม) ระบบ fallback ให้อ่านได้เหมือนกัน |
| ข้อความไม่ขึ้นใน OBS แต่ขึ้นในเบราว์เซอร์ | กด Refresh ที่ Browser Source หรือเช็กว่า URL ใช้ `127.0.0.1` ตรงกับพอร์ตที่รัน |
| ขึ้น `พอร์ต 4700 ถูกใช้งานอยู่แล้ว` | มีเซิร์ฟเวอร์ตัวเดิมเปิดอยู่ ปิดหน้าต่างนั้นก่อน หรือตั้ง `PORT` ใน `.env` |
| avatar ไม่ขึ้น เป็นตัวอักษรตัวแรกแทน | หา avatar ไม่เจอ (ชื่อผู้ใช้เปลี่ยน/บัญชีถูกลบ) หรือเน็ตบล็อก — ระบบจะไม่ลองซ้ำถี่ ๆ (แคช 10 นาที) |
| อยากดูแชทจากเครื่องอื่นในบ้าน | ตั้ง `server.host` เป็น `0.0.0.0` ใน `config.json` แล้วรีสตาร์ต |

## ข้อจำกัดที่ควรรู้

- โหมด YouTube แบบไม่ใช้ key พึ่งพา endpoint ภายในของ YouTube (ไม่ใช่ API ที่รับประกัน)
- โหมด YouTube API v3 ไม่มีรูป emoji ของช่อง (API ส่งมาเป็นข้อความ) — โหมด scrape ได้รูปครบ
- อ่านแชทอย่างเดียว ไม่ได้ส่งข้อความหรือสั่งมอดใด ๆ (ไม่ต้องใช้ token จึงปลอดภัยกับบัญชี)
- Kick อ่านแชทสาธารณะผ่าน WebSocket ของ Kick โดยตรง (ไม่มี API ทางการ) ถ้าโปรโตคอลเปลี่ยนอาจต้องอัปเดตโค้ด
- TikTok พึ่งพา `tiktok-live-connector` (แพ็กเกจภายนอก) ในการต่อ WebSocket แชทสด
- badge/อีโมทเสริมโหลดจากบริการภายนอก (Twitch GQL, BTTV, 7TV, FFZ) ถ้าล่มจะข้ามให้เอง
